# Cybersecurity Awareness Web App

An interactive web application designed to improve cybersecurity awareness by explaining phishing attacks, password security, and safe browsing practices.

## Features

* Explanation of phishing attacks
* Password strength checker
* Security awareness quiz
* Cybersecurity safety tips

## Technologies Used

* HTML
* CSS
* JavaScript
